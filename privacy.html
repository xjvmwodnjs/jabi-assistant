Privacy Policy

Last updated: 2026-11-17

JABI ("the app") is a personal assistant used by a single person — its own developer ("the owner") — for the owner's own Google account. It is not available to anyone else.

Data the app accesses

  • Gmail messages of the owner's account (read-only access, gmail.readonly).
  • Creating drafts and sending email (gmail.compose). Sending happens only after the owner approves that specific message with a personal PIN.

The app does not request access to contacts, calendar, files or any other Google service, and it cannot delete email.

How the data is used

  • Only to provide features the owner asks for: searching, reading, summarizing and replying to the owner's own email.
  • To answer a request, the relevant email text may be processed by an AI model provider chosen by the owner, under a zero-data-retention agreement. Before any text leaves the owner's computer, the app masks personal identifiers locally (for example e-mail addresses, phone numbers, card numbers).
  • Google user data is never sold, never used for advertising, and never used to train AI models.

Storage and security

  • There is no server. The OAuth token is stored only on the owner's own computer, encrypted with the operating system's user-bound encryption (Windows DPAPI).
  • The owner can revoke access at any time in the Google Account settings (Security → Third-party access).

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be raised through this site's GitHub repository.
